# Branding

- **Fonts:** Jost (headings, `--font-sans`) / Spectral (body, `--font-serif`)
- **Logo:** `public/logo.png` (grey wordmark, for light backgrounds), `public/logo-alt.png` (white, for the transparent header over imagery). See the logo-sizing note in CLAUDE.md → Troubleshooting.

## Color Palette
