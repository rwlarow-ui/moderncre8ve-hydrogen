### Key Insights

**Mobile outperforms by 60% on CTR** (0.50% vs 0.31%)
- Mobile users are more intentional, click more readily when they see the listing
- Despite weaker SERP positioning on mobile (21.4 vs 26.0)

**Desktop has higher impression volume** (12.5k vs 7.6k)
- Suggests more "research" behavior on desktop
- Mobile is more "ready to buy" but lower volume

**Tablet is negligible** (142 impr, 0 clicks)
- Not a priority focus

### Mobile Optimization Priorities

1. **Title Length** — Mobile shows ~55 characters vs 60 on desktop
   - Current: May be truncating key info
   - Fix: Lead with brand + main benefit (e.g., "ModernCre8ve | Handcrafted Scandinavian Dining Tables")

2. **Meta Description Clarity** — Mobile shows ~120 characters
   - Current: Possibly too generic
   - Fix: Emphasize unique value (custom, handcrafted, specific lead time)

3. **Core Web Vitals** — Mobile is slower
   - Test with PageSpeed Insights
   - Optimize images (furniture photos are usually large)
   - Reduce render-blocking resources

4. **Mobile SERP Appearance**
   - Use structured data (Rich Results) to show star ratings, price, availability
   - Ensure mobile preview is compelling (test with Google's SERP preview tool)

### ROOT CAUSE: GA4 / GSC Linkage Issue

**The Problem:**
- GSC reports 13 clicks to `/collections/mid-century-modern-dining-tables`
- GA4 reports 0 sessions to that same page
- This indicates **broken tracking or configuration issue**

**Likely Causes:**
1. GA4 event not firing on page load (check implementation)
2. GSC property not linked to GA4 property
3. Attribution window mismatch (30-day default)
4. Mobile traffic not being counted (iOS privacy)
5. Bot traffic in GSC but filtered in GA4

**Investigation Steps:**
1. In Google Search Console: Settings > Linked accounts → Verify GA4 is connected
2. In GA4: Admin > Data Sources → Ensure Google Search Console is authorized
3. In GA4: Reports > Traffic > Organic Search → Check if data appears
4. Use Google Analytics Debugger extension on a test page to verify page_view events fire
5. Check GA4 "Excluded traffic" settings (may be filtering legitimate visits)
