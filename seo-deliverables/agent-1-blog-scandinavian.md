## 5. Outbound Link Note

**Recommendation:** Add `rel="nofollow"` to all outbound links pointing to competitor retailer websites (e.g., IKEA, West Elm, Article, etc.). This prevents passing PageRank to competitors while still providing editorial value to readers. The links can remain visible for reader trust, but should not transfer SEO equity.

Example implementation:
```html
<a href="https://competitor-site.com" rel="nofollow" target="_blank">Competitor Name</a>
```
